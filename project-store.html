Web Application Individual Project (Front-End)

Modern E-Commerce: Interactive Storefront System

A responsive front-end online shopping application featuring instant product category filters, a slide-out shopping cart drawer, dynamic price calculation, and a multi-step checkout workflow.

Open Live Demo GitHub Repository
JavaScript (ES6+) CSS Flexbox & Grid Sliding Cart Drawer Client-side State Management Checkout Validation
Concept & Scope

Designed and built as a standalone front-end application to simulate modern retail UX without third-party frameworks. The project showcases mastery of client-side DOM manipulation, state handling for shopping baskets, dynamic badge calculations, and responsive mobile-first UI design.

Interactive Store Capabilities

01. Instant Category Filtering

Users can filter products by clothing, electronics, shoes, and discounts with immediate DOM layout reflow without page reloads.

02. Sliding Cart Drawer

A slide-out drawer accessible from any position, updating quantity counters, item totals, and grand subtotals in real time.

03. Deals & Discount Badging

Visual percentage off tags with original and discounted price comparison for enhanced conversion UX.

04. Multi-Step Checkout Workflow

A structured checkout screen handling customer contact details, shipping address, and simulated payment confirmation.
